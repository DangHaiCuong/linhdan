# Mèo Phi Hành Gia Trong Vũ Trụ 🐱‍🚀

Animation mèo phi hành gia lơ lửng trong vũ trụ - Thiết kế nền chuyển động cho website.

## 🌟 Tính năng

- ✨ Nền vũ trụ với gradient đẹp mắt
- ⭐ 200+ ngôi sao lấp lánh với hiệu ứng twinkle
- 💫 Sao băng bay qua màn hình
- 🐱 Mèo phi hành gia dễ thương với mũ trong suốt
- 🪐 Hành tinh quay quanh với hiệu ứng phát sáng
- ✨ Particles bay lên từ dưới lên
- 🖱️ Tương tác: Mèo di chuyển theo con trỏ chuột

## 🚀 Cách xem Demo

### Cách 1: Tải về và mở trực tiếp (Đơn giản nhất)

1. Tải file `index.html` về máy
2. Mở file bằng trình duyệt (Chrome, Firefox, Edge, Safari)
3. Thưởng thức!

### Cách 2: Chạy local server

```bash
# Clone repository
git clone https://github.com/DangHaiCuong/linhdan.git
cd linhdan

# Checkout branch
git checkout claude/floating-cat-space-animation-011CUuecdKyHB8bWzQCnd8rS

# Chạy server với Python
python3 -m http.server 8080

# Mở browser tại: http://localhost:8080
```

### Cách 3: Deploy lên GitHub Pages

1. Vào repository: https://github.com/DangHaiCuong/linhdan
2. Vào **Settings** → **Pages**
3. Chọn **Source**: Deploy from a branch
4. Chọn branch: `claude/floating-cat-space-animation-011CUuecdKyHB8bWzQCnd8rS`
5. Chọn folder: `/ (root)`
6. Nhấn **Save**
7. Đợi vài phút và truy cập: `https://danghacuong.github.io/linhdan/`

## 🎨 Tùy chỉnh

Bạn có thể tùy chỉnh trong file `index.html`:

- **Màu sắc vũ trụ**: Sửa `background: linear-gradient(...)` trong `.space`
- **Màu mèo**: Thay đổi `background` trong `.cat-head`
- **Tốc độ animation**: Điều chỉnh `animation-duration`
- **Số lượng ngôi sao**: Sửa `numberOfStars` trong JavaScript
